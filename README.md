# AIRepoHub

Discover. Install. Build. Plain-English guides to open-source AI GitHub repositories.

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm test       # unit + schema/RLS tests (PGlite)
pnpm build
```

Start with [CLAUDE.md](CLAUDE.md), then [docs/progress.md](docs/progress.md).
Requirements, architecture, schema, design system and the milestone plan live in [docs/](docs/).
Copy `.env.example` to `.env.local` when Supabase arrives (Milestone 2). Never commit secrets.
